Machine Quest was made to showcase the benefits of game balancing. By playtesting Machine Quest, it allows me to fix any bugs that are found.

## Installation and Dependencies
You would need Unity, and the version used is Unity 2022.3 LTS. After downloading the project, open it by adding through the project tab in Unity Tab.
